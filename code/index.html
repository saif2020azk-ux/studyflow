From idea to evidence.

A focused prompt engineering project, with room to grow.

How to use Studyflow

  1. Set your boundaries. Enter subjects, exam dates, target hours, and weekly availability.
  2. Make a local plan. Generate a checked timetable. Any unallocated work is shown clearly.
  3. Run the prompt experiment. In Prompt lab, copy v1 into your AI tool and save its actual response. Repeat with v2 and v3 on the same input.
  4. Validate and refine. Paste each JSON response, inspect the checks, and use the repair instruction if needed.
  5. Keep your evidence. Export the run history and save screenshots of actual runs for your report.

What the checks mean

A valid schedule stays within your available hours, uses known subjects, includes each date once, and schedules study strictly before the subject’s exam.

Completeness is checked separately. A schedule can follow every boundary and still leave work unfinished. This is shown as a shortfall.

Current scope

Up to 12 subjects and 120 days; 15-minute increments; repeating weekly availability. Sessions are daily allocations, not exact clock times. Breaks must be excluded from the hours you enter.

Your data

Plans and experiment logs are stored in this browser. Only the prompt text you choose to copy is sent to an external AI tool by you. Use made-up data for demonstrations.

Submission materials

The source project includes prompt versions, test data, actual local test results, workflow diagrams, a technical report starter, a Milestone 2 outline, and a demo script.
